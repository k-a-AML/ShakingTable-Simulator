# Real-Time Shaking Table 4-Building Seismic Simulator: Inelastic Collapse & Base-Isolation System

振動台4棟同時加振リアルタイム実験シミュレータ (スタンドアロン実行版)

---

## 1. 概要 (Overview)

本アプリケーションは、土木・建築構造実験室に設置された振動台において、**特性の異なる複数棟の建物モデルを同一の地震波で同時に加振**し、それぞれの動的応答、耐震性能、非線形塑性化、免制震効果等をリアルタイムかつインタラクティブに比較検証できる教育・研究用シミュレータです。

現行の耐震規基準等にもとづいて理想的に設計された**梁降伏先行・全体崩壊系の建築物**を想定しています。一般の方や初学者をメインターゲットとし、動的挙動を左右する**固有周期（階数と連動）**、**復元力特性**、**減衰定数**、**入力地震動**などにパラメータを限定化することで、重要なパラメータと全体挙動の関係を直感的に理解しやすくしています。

画面上のGUI操作から地震動や建物のパラメータを入力しながら、以下の現象を同一加振台上で同時に観察・追体験できます：

* **非線形履歴と残留変形:** バイリニアモデル（S造想定）や修正武田モデル（RC造想定）に基づく降伏後の剛性低下、エネルギー吸収ループ、および残留変形。
* **解析モードのリアルタイム切り替え:** 基本となる非線形MDOF（多自由度）モデル、および比較用の線形MDOF解析モードを搭載。
* **建物の損傷および限界表現:** 建物全体の変形角1/150を超えると構造体やガラスにひび割れや飛散エフェクトが発生。限界変形角（RC造: 1/50、S造: 1/30）超過で柱が軸力を負担できなくなったとみなして、建物全体が崩落するエフェクトが発生。
* **免震建物の性能把握:** 長周期・高減衰のアイソレータ系による変位集中と、上部構造の無変形・水平並進効果。
* **臨場感のある視点体験:** 実験の俯瞰だけでなく、路上や建物屋上（各5階相当）から地震時の揺れを疑似体験できる没入型カメラシステム。

> **【v1.0.0版について】**  
> 本ソフトウェアでは初学者向けの分かりやすさを優先し、パラメータ数を絞るため**巨視的な非線形MDOFモデル**を採用しています。実際の局所的な破壊性状とは異なる概念的シミュレーションであることをご留意ください。

## 2. 実験仕様・構造モデルの諸元 (Specifications)

加振台上に配置された4棟（パラメータ可変の3棟 ＋ 固定の免震1棟）の標準構造諸元です。

| 項目 | 設定値・仕様 | 備考 |
| :--- | :--- | :--- |
| **振動台駆動** | **2軸水平加振テーブル**（ストローク変位制御） | 地動との動的関係性が成立する連成解析 |
| **No.1 鉄骨造 (S造)** | 復元力特性: **バイリニアモデル**<br>固有周期: $T = 0.02H$ | 全体の限界変形角 1/30 超過で崩壊判定 |
| **No.2 鉄筋コンクリート造 (RC造)** | 復元力特性: **修正武田モデル**<br>固有周期: $T = 0.03H$ | $T$ は曲げ降伏荷重・変形角に対する割線剛性に対して規定。全体の限界変形角 1/50 超過で崩壊判定 |
| **No.3 免震モデル** | 免震層 $T_i = 4.0\,\mathrm{s},\ h_i = 0.2$ | 上部構造剛体。線形ばね＋ダンパーによる免震効果比較用 |
| **高さ方向への剛性分布** | 剛性分布はAi分布による必要層せん断力と比例を仮定 ｜各層耐力は復元力特性の降伏耐力係数をC0とみなしてAi分布で決定 |
| **減衰モデル** | 初期剛性比例型を仮定 | -- |
*免震モデルの外観は、近畿大学東大阪キャンパス1号館を採用しています

## 3. 起動方法と動作要件 (Quick Start & Requirements)

### 3.1 動作要件
* **対応OS:** Windows 10 / 11 (64-bit)
* **グラフィックス:** Direct3D 11 / 12 (Compute Shader および Forward+レンダリング対応) GPU（NVIDIA GeForce GTX 1060 以上推奨）
* **ディスプレイ解像度:** 1920 × 1080 (Full HD) 以上推奨

### 3.2 実行手順
1. ダウンロードした ZIP ファイル（`ShakingTable_Simulator_v1.0.0.zip`）を右クリックし、**「すべて展開（解凍）」** します。
2. 展開されたフォルダ内にある **`ShakingTable-Simulator.exe`** をダブルクリックして起動します。

> **【注意】**  
> ZIP ファイルを展開せずに直接開いて実行すると、アセットやシェーダーの参照が切れ、テクスチャ欠落や強制終了の原因となります。必ず解凍を行ってから実行してください。

## 4. 操作方法 (Controls)

### 4.1 カメラ・視点切替 (Camera Modes)
単なる俯瞰にとどまらない多様な視点・角度への切り替えが可能です。

*  **俯瞰モード:** 実験室全体と4棟の挙動差を俯瞰する基本画角[1～6]
*  **路上体験視点:** 現実的な体験に近い、建物を見上げる地上レベルからの臨場感ある視点(360度回転可)
*  **建物上体験視点:** 建物上（各5階相当）に乗った状態での疑似体験(90度回転可)


### 4.2 画面UI・シミュレーション操作 (GUI Controls)
画面上のコントロールパネルから制御します。

1. **地震波選択パネル:**
   * **El Centro (1940):** インペリアルバレー地震（標準的な耐震ベンチマーク波）
   * **Taft (1952):** カーンカウンティ地震（標準的な耐震ベンチマーク波）
   * **Hachinohe (1968):** 十勝沖地震 （標準的な耐震ベンチマーク波） 
   * **JMA Kobe (1995):** 兵庫県南部地震
   * **築館 (2011):** 東北地方太平洋沖地震    
   * **三崎町 (2021):** 能登半島地震
   * **豊能町 (2026):** 熊本地震   
   * **正弦波:** 振動数 2.0, 1.0, 0.5, 0.33, 0.2 Hz（各50Kine相当）
2. **加振倍率スライダ:**
   * 入力地震動の最大加速度を **0.1倍 〜 10.0倍** の範囲で可変スケーリング。
3. **建物諸元変更:**
   * 対象建物モデル：　front-Right(手前-右側建物)/Back-Left(奥側-左側建物)/Back-Right(奥側-右側建物)
   * 層数: 5～35　　階高は鉄骨造5ｍ、RC造4ｍとし、固有周期Tを(0.02+0.01α)Hで算定
   * 減衰定数:　0～100%
   * 復元力特性:　鉄骨造(バイリニア)/RC造（修正武田モデル）
   * 解析モード： 非線形MDOF /  線形MDOF(修正武田モデルの場合　降伏点の割線剛性で剛性を評価)
   * 降伏耐力係数（荷重/重量　C0相当）: 0.2～5.0の範囲で0.05ピッチで設定可
4. **リアルタイム履歴ループ描画 :**
   * 画面左下に、3棟のリアルタイム復元力特性（層せん断力 $Q$ - 最上部変形角 $\theta$）をプロットします。
     * **Front-Right:** 手前-右側建物
     * **Back-Left:** 奥側-左側建物
     * **Back-Right:** 奥側-右側建物
     * 全体変形角-ベースシア/各層変形角-層せん断力　の選択
5. **加振制御ボタン:**
   * 地震波の再生・一時停止 / 先頭への巻き戻し / 完全初期化
